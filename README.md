# ChopList

A pre-order tool for home food sellers in Lagos: one link for the weekly menu,
orders without sign-up, payment matching by reference code, and a prep sheet.

AltSchool Tinyuka 2025 Capstone, Group 1.

## Structure

    backend/    Node.js, Express, TypeScript API
    frontend/   React web app (PWA)
    docs/       API contract and project docs
